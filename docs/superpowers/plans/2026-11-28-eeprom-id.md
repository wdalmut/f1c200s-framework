**Goal:** lo schema v1.0 dei 64 byte dell'EEPROM di identificazione, con parser C e tool `som-id` in una repo propria provata su armv5, armv7, arm64 e x86_64, e la sua integrazione nella build EGARE (package Buildroot, celle nvmem, `make check`).

**Tech Stack:** C99, GNU make, bash, Python 3 (solo nei test), GitHub Actions con cross-compilatori Ubuntu e qemu-user-static; Buildroot 2026.02.3 (`generic-package`, helper `github`), Linux 6.12.111 (at24, nvmem `fixed-layout`).

## Global Constraints

- Repo `som-id`: tutto in inglese (README, `SPEC.md`, commenti, messaggi). Ogni sorgente con `SPDX-License-Identifier: MIT` e `Copyright (c) 2026 Walter Dal Mut`; `LICENSE` MIT con lo stesso titolare.

- Magic `53 4D 49 44` ("SMID"), versione `0x10`, record di 64 byte, CRC-16/CCITT-FALSE (poly `0x1021`, init `0xFFFF`, non riflesso, xorout `0`) su `0x00–0x3D`, scritto LE a `0x3E`. `0x29B1` su `"123456789"`.
- Offset: magic `0x00`/4, versione `0x04`, rev `0x05`, prodotto `0x06`/2 LE, variante `0x08`, DDR `0x09`, RAM MiB `0x0A`/2 LE, riservati `0x0C`/4, MAC0 `0x10`/6, MAC1 `0x16`/6, seriale `0x1C`/12, riservati `0x28`/22, CRC `0x3E`/2. Da `0x40` a `0xFF` il tool non scrive.
- MAC in ordine di rete; `FF:FF:FF:FF:FF:FF` = porta assente.
- Seriale `PPYYWWNNNNNC`, alfabeto `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ`, `C` = Luhn mod 36 sui primi 11; `MA264800017` → `C`.
- `src/som_id.c` e `src/som_id.h` includono solo `<stdint.h>`, `<stddef.h>`, `<string.h>`. Accesso al buffer solo byte per byte.
- Nel DT: niente `read-only`, niente `wp-gpios` su `eeprom@50`, niente `nvmem-cells` verso le celle MAC.

};

/* bits returned by som_id_invalid() */
#define SOM_ID_INV_PRODUCT  (1u << 0)
#define SOM_ID_INV_REV      (1u << 1)
#define SOM_ID_INV_RAM      (1u << 2)
#define SOM_ID_INV_MAC0     (1u << 3)
#define SOM_ID_INV_MAC1     (1u << 4)
#define SOM_ID_INV_SERIAL   (1u << 5)
#define SOM_ID_INV_RESERVED (1u << 6)

struct som_id {
	uint8_t  version, rev, variant, ddr;
	uint16_t product, ram_mib;
	uint8_t  mac[2][6];
	char     serial[13];          /* 12 characters + '\0' */

int  som_id_serial_valid(const char *s12);   /* full format */
int  som_id_mac_absent(const uint8_t mac[6]);
int  som_id_mac_valid(const uint8_t mac[6]); /* unicast and not all zero */

- [ ] **Step 4: implementare `src/som_id.c`**

- `som_id_crc16`: bit per bit, nessuna tabella.
- `som_id_parse`: vergine (64 × `0xFF`) → magic → CRC → major (`version >> 4 != 1` → `BADVERSION`, riempie solo i campi dell'intestazione). Con `OK` riempie tutto; il seriale si copia tale e quale con `'\0'` in fondo.
- `som_id_build`: azzera i riservati, scrive i campi agli offset delle Global Constraints e il CRC.
- `som_id_invalid`: la tabella "Campi non validi" del design. Con `BADVERSION` solo prodotto, rev, RAM e riservati `0x0C–0x0F`; riservati `0x28–0x3D` solo se `(version & 0x0F) == 0`; con altri stati restituisce 0.

- `som_id_serial_check`, Luhn mod 36:

```c
int factor = 2, sum = 0;
for (int i = 10; i >= 0; i--) {
	int cp = index_of(s11[i]);            /* -1 if outside the alphabet -> return 0 */
	int addend = factor * cp;
	factor = (factor == 2) ? 1 : 2;
	sum += addend / 36 + addend % 36;
}
return alphabet[(36 - sum % 36) % 36];
```

- `som_id_mac_local`: `mac[0] & 0x02`. Multicast: `mac[0] & 0x01`.
